\# 🎮 Cuidado espacial: limpiemos el universo



Videojuego educativo accesible 2D creado con \*\*Godot 4\*\*, diseñado para enseñar \*\*salud bucal\*\* a niños con \*\*discapacidad visual\*\*.  

Incluye narrativa tipo cuento y tres minijuegos con retroalimentación sonora y táctil.



---



\## 🧠 Objetivo

Desarrollar un prototipo accesible con distintos modos de interacción (ceguera total / visión parcial) que enseñe higiene bucal de forma lúdica.



---



\## 🕹️ Estructura del juego

1\. Historia 1 → Minijuego 1: \*Esquivar el asteroide\*  

2\. Historia 2 → Minijuego 2: \*Cepillar el asteroide\*  

3\. Historia 3 → Minijuego 3: \*Búsqueda del tesoro\*  

4\. Cuestionario final



---



\## ⚙️ Tecnologías

\- Motor: \*\*Godot 4 (2D)\*\*

\- Lenguaje: \*\*GDScript\*\*

\- Plataforma: \*\*Android\*\* (exportable a Web)

\- Audio: MP3/WAV narrado

\- Vibración: API nativa Android
